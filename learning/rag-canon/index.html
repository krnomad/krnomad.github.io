01 · 개념 구분

Indexing과 Fine-tuning은 전혀 다릅니다

검색 자료를 늘리기

Indexing / Embedding

기존 문서를 추출·정리·분할하고 숫자 벡터로 표현해 검색 DB에 보관합니다. 질문할 때 이 자료를 다시 찾을 수 있습니다. 답변 LLM의 가중치는 바뀌지 않습니다.

모델의 동작을 바꾸기

Fine-tuning

훈련 예제로 모델 가중치를 수정합니다. 최신 문서 추가와 출처 조회를 대신하는 기본 기능으로 혼동하면 안 됩니다.

RAG는 그중 첫 번째 흐름을 이용하여 답변을 생성합니다. 검색 결과를 모델에 근거로 제공하되, 출처가 실제 주장을 뒷받침하는지는 따로 확인합니다.

04 · 의미 공간
임베딩: 문장의 뜻을 숫자로 표현합니다
문서를 표현하는 벡터와 질문 벡터의 방향·거리를 비교해 관련 문서를 찾습니다. 아래 2차원 예제는 사람이 만든 좌표이며 실제 학습 모델의 고차원 벡터가 아닙니다.


체험 · 사람이 만든 2차원 예제 / 실제 모델 출력 아님







거리 계산 결과
코사인 유사도 = 두 화살표가 같은 방향을 보는 정도.
cosine distance = 1 − cosine similarity
실제 vec0는 현재 cosine distance를 사용하며 거리가 작을수록 가깝습니다. 여기서는 각도를 직접 정해 원리를 보여 줍니다. 2차원으로 실제 검색 품질을 재현하지는 않습니다.






먼저 각도를 움직여 회복·공격 문서의 순위 변화를 보세요. 이후 TensorFlow Projector에서 실제 고차원 표현을 2D/3D로 축소해 탐색해 보시면 좋습니다. 단, 차원 축소 그림에서 가까운 점이 모든 원래 차원에서도 항상 가장 가까운 것은 아닙니다.

RRF 순위 합치기 · 교육용 고정 순위
점수의 단위가 다르면 ‘순위’를 합칩니다
문서 A가 키워드 1위·의미 3위, 문서 B가 키워드 2위·의미 1위일 때:
RRF는 각 채널에서 1/(60 + 순위)를 더합니다. 현재 코드도 이 공식을 쓰지만, 정확 일치·명시 이름 우선과 의미 후보 재정렬이 추가되어 최종 순위가 이 단순 예제와 같지는 않습니다. 출력 score는 확률이 아닙니다.
RRF는 각 검색 방식의 점수 크기가 달라도 순위 자체를 합칠 수 있습니다. 실제 서비스는 이름 우선 규칙이나 후단 재정렬 등을 추가할 수 있습니다.
